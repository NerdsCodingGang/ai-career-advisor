# Skill taxonomies (lightweight)

Methodology only — does not advance pipeline stages.

Not a universal encyclopedia — a **grouping aid** for skill-table coverage checks and market normalization.

## Suggested group lenses

- Cloud & infra  
- Delivery / CI-CD  
- Data & storage  
- Quality / testing  
- Observability & incidents  
- Security & access  
- Product / stakeholders  
- Leadership / mentoring  
- Domain (finance, gaming, …)  
- AI / tooling practices  

Adapt groups to the candidate’s target track. One **group per turn** in skill verification.

## Normalization

Market wording → canonical `id` via `market-research.yaml` `normalization.aliases`  
(e.g. “CI/CD”, “Jenkins pipelines” → `ci_cd`).

## Kind tags

Reuse employment/skills `kind` enums; don’t invent parallel type systems.
