# Workshop SHORT mode

Methodology only — pacing hints when `candidate/profile.yaml` → `session.mode: SHORT`.

Does **not** skip conversation rules (one question, STOP, no autofill).

## Defaults when SHORT

| Area | FULL | SHORT (~3 h workshop) |
|------|------|------------------------|
| Archaeology focus roles | ~5 | **3–4** newest / HIGH relevance |
| LOW/SKIP roles | light pass | light pass or skip |
| Achievement mining (`03`) | standard | **light** — only clear wins; skip forced mining |
| Market postings (`04`) | per workflow | **~10** near target role |
| Competency grilling (`05`) | all HIGH | HIGH only; defer rest |
| Skill verification (`06`) | full table | **critical skills** for target role |
| Profile completion (`07`) | full | competency-profile + minimal seniority; defer deep seniority debate |
| CV (`08`) | full gates ideal | cv-plan + draft CV; flags may be relaxed on workshop floor with facilitator OK |

## Token discipline (SHORT)

- Read: `profile.yaml` + active `workflow/<stage>.md` + **one** active employment file when in archaeology/grilling.
- Write: **one primary file per turn** — see `SKILL.md` Write budget.
- Do **not** load `references/contracts-full.md` unless dispute or gate judgment.
- Do **not** load full `skills.yaml` every turn — current group / row only.
- Documents in `candidate/sources/` — read once at intake; do not re-paste in chat.
- Market (`04`): batch sample → one `market-research.yaml` write → then chat.

## Setting mode

Workshop starter `_blank` defaults to `session.mode: SHORT`.  
Full discovery: set `session.mode: FULL` in `profile.yaml`.
